# 02 · 地图位置、修改与新增

## 1. 三种地图文件各做什么

| 文件 | 用途 |
|---|---|
| `map_data/map_01.png`等 | 地图预览图；改图片不会自动改变仿真 |
| `map_data/map_01.json`等 | 编辑器几何：墙体、箱体、出生区域、处置区域；不是炸弹布局文件 |
| `src/swarm_rescue/maps/map_01.py` | 实际地图类：场地大小、起点、处置区、时限、区域等 |
| `src/swarm_rescue/maps/walls_01.py` | 实际墙体与箱体构建 |
| `fixtures/bombs/Map01_historic.json` | 独立炸弹布局：map_name、zones_config、bombs世界坐标 |

模拟器最终使用Python地图。PNG/JSON是编辑和预览资料；改完JSON要重新生成代码。控制算法不得导入这些真值文件。

## 3. 新增Map09，推荐顺序

### 第一步：准备并编辑JSON

将`templates/map_09.json`复制为`map_data/map_09.json`。模板是新地图起点，不属于已注册的第9张地图。运行：

```powershell
.\run.ps1 MapEditor
```

在编辑器中通过“打开/加载”选择JSON，编辑墙体、障碍、蓝色出生区域、绿色处置区域，再保存JSON。不要仅保存截图。避开起点处墙体，给10机启动和载弹转弯留出空间。

### 第二步：JSON生成地图Python

独立环境命令：

```powershell
.\.venv\Scripts\python.exe -m swarm_rescue.tools.json_to_map map_data/map_09.json --name 09 --maps-dir src/swarm_rescue/maps
```

本机复用旧环境时也可明确从本目录加载：

```powershell
$env:PYTHONPATH = Join-Path $PWD 'src'
& 'C:\Users\25923\Documents\Codex\2026-09-16\x20\swarm-eod-main\.venv\Scripts\python.exe' -m swarm_rescue.tools.json_to_map map_data/map_09.json --name 09 --maps-dir src/swarm_rescue/maps
```

生成`map_09.py`、`walls_09.py`，类名为`Map09`。`--name 09`不是`--name Map09`。再次生成会覆盖同名地图文件，手工增加的特殊区域要保留或重新接入。

**生成器目前默认7200步、1440秒。** 在`map_09.py`中按真实比赛公布值修改`_max_timestep_limit`和`_max_walltime_limit`。例如仅用于本地示例可设5000/180；不要把扩大时限的成绩当成比赛成绩。Map01-08的原时限不能为提分而改大。

### 第三步：注册地图

在`src/swarm_rescue/launcher.py`现有地图import附近加入：

```python
from swarm_rescue.maps.map_09 import Map09
```

启动器和回放通过这个模块里的类名查找地图。仅修改`maps/__init__.py`或只放PNG，不会自动注册。

### 第四步：设置配置和10枚炸弹

把`templates/rescue_Map09.yml`复制到`config/rescue_Map09.yml`。`map_name`必须为`Map09`，启用统计和状态记录。若增加特殊区，还要在Python地图里构建它们，配置中的`zones_config`再启用对应类型；只改YAML不会凭空产生区域。

运行炸弹编辑器：

```powershell
.\run.ps1 BombEditor -Map Map09 -File fixtures/bombs/Map09_custom.json
```

左键添加、右键删除最近炸弹，J导出JSON，K清空，I导入，Q退出。放10枚，避免初始与墙/箱体重叠，不要放在处置区里；保证能够接近且载弹有可通过的路线。空机圆盘可达不等于载荷转弯可达。

炸弹JSON使用**世界坐标**，示例结构：

```json
{"map_name":"Map09","zones_config":[],"bombs":[{"x":100.0,"y":-200.0,"theta":0.0}]}
```

这里只展示一条结构；正式测试需要10条。图片/编辑器的坐标原点在左上，世界坐标原点在中央、y向上，不能直接抄图片像素；导出工具会转换坐标。

### 第五步：先检查再完整跑

```powershell
.\run.ps1 Check
.\run.ps1 Run -Map Map09 -File fixtures/bombs/Map09_custom.json -Headless
```

再看CSV、回放和碰撞位置，换布局及种子重复测。添加地图会改变整个模拟器源码哈希，后续结果记录新哈希，这是正常的；不要把修改后地形的成绩归给旧地形。

## 4. 特殊区域

`NO_COM_ZONE`禁通信；`NO_GPS_ZONE`使GPS/指南针失效，里程计保留；`KILL_ZONE`在新增复杂图中使用`LethalKillZone`永久毁伤实现。原普通KillZone语义不同。JSON转换器不会自动完成这套特殊区逻辑；参考`map_06.py`、`map_07.py`、`map_08.py`及[复杂区说明](reference/复杂干扰地图说明.md)。区域应能安全绕行，布局文件和运行配置的区域设置要一致。
