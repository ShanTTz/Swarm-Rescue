# 01 · 安装与运行测试

所有命令都在项目根目录执行。比赛控制器只使用合法运行时观测；固定炸弹文件由模拟器读取，不提供给算法。

## 1. 本机立即使用

```powershell
cd C:\Users\25923\Desktop\Swarm-Rescue
.\run.ps1 Test
.\run.ps1 Check
.\run.ps1 Smoke
```

- `Test`：180项选定回归，包括处置区修复、导航、任务进展、真值接口、评分和记录检查；`./run.ps1 Test -Suite`执行完整384项测试。
- `Check`：提交结构与禁止接口检查。
- `Smoke`：120步CPU物理/competition检查，包含定位、语义失效与恢复；**这不是完整成绩测试**。

`run.ps1`自动选取本目录`.venv`或本机原已验证环境，并设置`PYTHONPATH=本目录/src`。两个目录的代码不会混用。若PowerShell拒绝执行此项目脚本，可仅对这次执行使用：

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1 Test
```

## 2. 给队友或在本目录建独立环境

要求Python 3.11、可用显卡驱动/OpenGL。`--headless`只关闭显示窗口，射线传感仍需要图形上下文。

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -c constraints-windows-py311.txt -e ".[dev]"
.\run.ps1 Check
.\run.ps1 Test
```

依赖按`constraints-windows-py311.txt`约束；不建议直接复制旧虚拟环境。建立本地环境后，统一入口会优先使用它。

## 3. 单图完整比赛

```powershell
# 无窗口评分测试
.\run.ps1 Run -Map Map01 -Layout historic -Headless
.\run.ps1 Run -Map Map03 -Layout stratified -Headless
.\run.ps1 Run -Map Map05 -Layout edge_pairs -Headless

# 去掉Headless即可实时显示仿真
.\run.ps1 Run -Map Map01 -Layout historic

# Map1已知困难布局
.\run.ps1 Run -Map Map01 -Layout stress_far_wall_five_pairs -Headless
```

布局参数：`historic`历史、`stratified`分散、`edge_pairs`边缘成对。普通三布局适用于Map01-05。默认种子12345；另一个种子可用`-Seed 314159`。每局10架无人机、10枚炸弹，固定原时限；会保存CSV、NPZ、日志和输入布局。

统一工具会清理旧试验环境变量，设置正式v13.1的默认策略。它不会读取旧成绩缓存；每次运行建立新的结果目录。

## 4. 五图各三个布局共15局

```powershell
.\run.ps1 Run -Suite -Headless
```

会串行运行15局，在`results/v13_1_时间戳/summary.json`持续保存结果。不要同时跑多个评分仿真：墙钟时限和碰撞损伤冷却会使CPU负载影响成绩。修改算法后也可运行此工具，结果会记录实际源码哈希；批量过程中若源码变化会停止。

## 5. 自己的炸弹布局/新地图

```powershell
.\run.ps1 Run -Map Map09 -File fixtures/bombs/Map09_custom.json -Headless
```

新地图需要先注册，详见[地图说明](02_地图与新增地图.md)。蓝方赛道的本工具要求布局文件与地图名称一致，且包含10枚炸弹。文件内`zones_config`作为仿真区域开关；地图、布局与区域设置要一致。

Map06-08已有默认复杂区布局：

```powershell
.\run.ps1 Run -Map Map06 -Headless
```

这类布局默认开启文件中声明的禁通信、无GPS和杀戮区，当前算法并未完成这三张图的整轮能力验证。

## 6. 原始启动命令

本地环境安装后也可绕过包装工具直接运行：

```powershell
.\.venv\Scripts\python.exe -m swarm_rescue.launcher --competition --headless --config config/rescue_Map01.yml --bombs-file fixtures/bombs/Map01_historic.json
```

直接启动默认输出到`results_swarm_rescue/`；统一工具输出到`results/`。直接命令不替你重设随机种子或清理旧试验变量。公开Map01-05本身没有预置炸弹，不传真实布局的空图不能作为成功成绩。

## 7. 输出文件

每局目录有`team006_stats.csv`（正式统计）、`recordings/*.npz`（轨迹回放）、`run.log`（含状态事件）、`metrics.json`（版本/输入/结果）、`eval.yml`和`bombs_input.json`（复核输入）。正常运行还可能产生模拟器的报告PDF。

出现错误时先看该局`run.log`。提交检查通过和单元测试通过不等于所有炸弹布局都会全部归位，最终看CSV中的`Rescued Percent`和实际处置数。
