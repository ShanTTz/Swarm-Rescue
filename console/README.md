# Swarm-Rescue 控制台

一个完全独立于仿真核心的本地控制面板：把命令行操作（运行、回放、地图新增、测试、结果查看）变成网页按钮。
**不改 `run.ps1`、不改 `src/`、不改任何核心脚本**；地图、布局、回放索引、结果目录都在每次请求时动态扫描，
核心代码更新后无需改动本目录。

## 启动

在本目录打开 PowerShell：

```powershell
cd C:\Users\25923\Desktop\Swarm-Rescue
.\console\start.ps1
```

浏览器会自动打开 `http://127.0.0.1:8765`（换端口：`.\console\start.ps1 -Port 9000`；不开浏览器：`-NoBrowser`）。

## 功能对照

| 页面 | 按钮 | 等价命令 |
|---|---|---|
| ▶ 运行 | 选地图卡 + 布局 + seed + ▶ 开始运行 | `.\run.ps1 Run -Map Map01 -Layout historic -Seed 12345 [-Headless]` |
| ▶ 运行 | 后台运行（无窗口） | `-Headless` |
| ▶ 运行 | 全套15局 | `--suite` |
| ⏵ 回放 | 内置/本地录像表里点 ▶ | `.\run.ps1 Replay …` / `play_replay.py --file xx.npz` |
| 🗺 地图管理 | ①新建JSON ②墙体编辑器 ③生成代码 ④注册 ⑤配置 ⑥炸弹编辑器 ⑦提交检查 | docs/02 五步流程 |
| 🧰 工具 | 回归/全量测试、提交检查、冒烟、分数汇总 | `Test [-Suite]` / `Check` / `Smoke` / `Scores` |
| 📊 结果 | 批次浏览、逐局成绩、回放、打开目录 | 读 `results/*/…/metrics.json` |

右侧「⚙ 任务」面板实时显示所有正在跑/已结束的任务与完整日志，可随时 ⏹ 停止（结束整个进程树）。

## 注意

- 回放窗口打开后处于暂停状态，按**空格**开始。
- 地图注册会修改 `launcher.py`（自动备份到 `console/logs/backups/`）；新增地图会改变源码哈希，属正常现象。
- 炸弹编辑器：左键添加、右键删除、**J** 导出 JSON、**K** 清空、**I** 导入、**Q** 退出。
- 服务只监听 127.0.0.1，供本机使用；`console/logs/` 为任务日志，已加入 .gitignore。
